Your Steam library, at home on your Linux desktop

Superlion shows the games you've installed and the ones you own, and lets you browse the store, sort out launch options, Proton builds and artwork, and stream games through Sunshine, all without opening Steam's own window.

Install from COPR View on GitHub

Features

Your whole library in one place

Installed games, games you own but haven't installed, and non-Steam games, side by side. Filter by Steam's collections or your own, search by name, initials or app ID, and sort or group by size, last played, release date or genre.

A page for every game

Trailers, screenshots, news and install details. Play turns into Stop while a game's running, and games can be moved to another drive, uninstalled or removed from here.

Launch options without the guesswork

Switch over 100 common settings on and off, with warnings for ones that clash or do nothing. Presets save the combinations you use often.

The Steam store, natively

Browse with local prices, watch trailers, and manage your wishlist and cart in the same window as your library.

Downloads, and updates when you want them

See what Steam's downloading, with progress on each game's cover. Start waiting updates or resume paused ones without opening Steam's window.

And the rest

Library folders
See what each drive holds, then move, uninstall, hide or collect several games at once.
Proton builds
Install and update GE-Proton and Proton-CachyOS from Preferences.
Non-Steam games
Add them from Files and match them to a store game for its artwork and news. Artwork can also come from SteamGridDB.
Mod managers
Link one to a game and launch it from the game's page, with the same Proton and launch settings as a game.
Streaming
Send games to Moonlight through Sunshine. Superlion matches your display to the client's resolution, refresh rate and HDR, then puts it back afterwards.

Steam stays out of the way

Steam keeps some of its files in memory and overwrites them when it quits, so Superlion only writes to them while Steam's closed. When a change needs Steam to restart, it restarts quietly in the background, and only asks first if a game would close. Steam's settings files are backed up before they're written.

Install

On Fedora, install Superlion from COPR:

sudo dnf copr enable solartw/superlion
sudo dnf install superlion

Store trailers need an H.264 decoder, such as gstreamer1-plugin-libav or gstreamer1-plugin-openh264. The first time you open Superlion, a setup wizard finds your Steam installation, account and library folders.
